# Image credits

Every product photograph in `public/img/products/` comes from Wikimedia Commons.
The machine-readable record is `data/product_image.csv`; this file is its
human-readable form, which the CC BY and CC BY-SA licences require us to publish.

They are fetched in two steps — `npm run images:fetch` resolves which image each
product needs, `npm run images:download` pulls the files — so nothing here is
guessed: every row names the article the image illustrates, its licence and its
author.
